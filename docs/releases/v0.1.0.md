# Studypal v0.1.0

**这次，有人陪你一起学。**

首个已发布的 Android 可执行版本，把专注计时、角色陪伴和成长反馈放进一间复古书房。

**[下载 Android APK](https://github.com/icode-chicken-hotpot-stew/Studypal/releases/download/v0.1.0/app-release.apk)** · [GitHub Release](https://github.com/icode-chicken-hotpot-stew/Studypal/releases/tag/v0.1.0)

## 本版内容

- **专注节奏**：默认 25/5 番茄钟、自定义专注／休息时长、有限循环、暂停／继续／重置。
- **连续体验**：本地快照保存，回前台与重启后按时间同步计时状态。
- **角色陪伴**：Live2D 学习／休息动作、出场与点击联动，六类本地场景对话。
- **成长反馈**：XP 结算、Lv.1–Lv.10 成长、对话等级解锁与卷轴进度。
- **书房氛围**：3 首背景音乐、播放控制、音量调节、阶段与界面交互音效。
- **专注提醒**：专注中切后台时安排本地监督通知，返回或暂停／重置后取消待发送提醒。

## 安装与使用

下载 `app-release.apk` 安装到 Android 设备，横屏启动后点击左上角番茄按钮开始。首次启动可按需授予通知权限。无需注册账号或配置后端服务。

## 当前版本边界

- 黑板时长为 XP 折算值，尚无完整历史明细。
- 通知调度为 3／6 分钟，当前通知正文存在 5／10 分钟的描述差异；实际送达受系统调度影响。
- 数据与对话均在本地，尚无账号同步或云端对话服务。

当前大版本开发已告一段落，短期暂无新功能迭代计划。更多说明见 [维护状态](https://github.com/icode-chicken-hotpot-stew/Studypal/blob/main/docs/maintenance.md)，问题可反馈至 [Issues](https://github.com/icode-chicken-hotpot-stew/Studypal/issues)。
