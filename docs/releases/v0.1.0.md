# Studypal v0.1.0

首个可执行版本，面向 Android 设备交付。

## 包含内容

- 横屏陪伴式专注学习主界面
- 番茄钟计时与专注/休息切换
- XP 与等级成长反馈
- Live2D 角色陪伴与多场景对话
- 背景音乐、音效与基础播放控制
- 本地通知与后台监督提醒

## 安装包

- 目标产物：`build/app/outputs/flutter-apk/app-release.apk`
- Android 应用标识：`com.icode.studypal`
- 应用显示名：`Studypal`
- 版本号：`0.1.0+1`

## 备注

- 当前 release 构建使用仓库默认签名配置，适合首轮内测分发。
